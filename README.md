# Resume

Printable one-page curriculum vitae for **Luis Huachaca Vargas**.

Live: [luis-huachaca-hv.github.io/Resume](https://luis-huachaca-hv.github.io/Resume/)

## Print

1. Open `index.html` in Chrome or Firefox (or the GitHub Pages URL).
2. Choose **EN** or **ES**. The same language is used when you print.
3. Click **Print / Save PDF**, or use the browser print dialog.
4. Paper: **A4**. Margins: **none**. Enable **background graphics**.
5. Save as `Luis-Huachaca-Vargas-CV.pdf` (the page title includes the language).

The page is sized to a single A4 sheet (`210mm × 297mm`). No JavaScript framework: semantic HTML and print CSS, so GitHub Pages can serve it as-is.

## Local preview

```sh
python3 -m http.server 8080
```
